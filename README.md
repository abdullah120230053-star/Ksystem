# نظام إدارة كُتّاب تحفيظ القرآن والاشتراكات (Ksystem)

نظام سحابي متكامل لإدارة شؤون طلاب كُتّاب تحفيظ القرآن الكريم، حساب الاشتراكات الشهرية وتطبيق عروض الإخوة آلياً، تسجيل الحضور والغياب اليومي، وإصدار المستندات الرسمية وكشوف المتأخرات بصيغة PDF.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **محرك احتساب عروض الإخوة (Sibling Pricing Engine)**
   - احتساب اشتراك العائلة ديناميكياً بناءً على عدد الإخوة النشطين.
   - دعم التخفيضات التلقائية لكل شريحة (طالب، أخوان، 3 إخوة، إلخ).
   - إمكانية استثناء طالب باشتراك مخصص أو دعم كفالة مع الحفاظ على خصم بقية الإخوة.
   - دعم الاستثناءات المباشرة على مستوى الأسرة في الحالات الخاصة.

2. **كشف الحضور والغياب اليومي (Attendance Tracking)**
   - تسجيل فوري بنقرة واحدة (حاضر / غائب / متأخر).
   - خيارات تحديد جماعي للكل (تحديد الكل حاضر / غائب).
   - مؤشرات ونسب التزام شهرية لكل طالب وحلقة.

3. **إدارة الاشتراكات والتحصيل (Payments & Financial Accounting)**
   - كشف الطلاب والعائلات غير المسددين والمتأخرين مع إمكانية التحصيل الفوري.
   - دعم السداد الكامل والجزئي مع توثيق المتبقي.
   - سجل حركات مالية مؤرخ (Transactions Stream) يوثق النقد والتحويلات.

4. **المستندات الرسمية وتصدير الـ PDF (Official PDF Documents)**
   - إصدار كشوف رسمية A4 مجهزة للطباعة والحفظ بصيغة PDF بجودة عالية عبر `html2pdf.js`.
   - كشف المتأخرات والاشتراكات غير المسددة مع الترويسة الرسمية وختم الإدارة.
   - تصدير كشوف المتأخرات إلى ملفات Excel / CSV.

5. **الأمان وصلاحيات المستخدمين (Role-Based Access Control - RBAC)**
   - **المدير (Admin)**: صلاحيات كاملة لإدارة الأسعار، الطلاب، والعائلات والمالية.
   - **المعلم (Teacher)**: تسجيل الحضور والغياب واستعراض بيانات الطلاب دون صلاحية تغيير الأسعار أو المالية.
   - **المراقب (Viewer)**: صلاحيات قراءة واستعراض فقط.

6. **سجل التدقيق والعمليات (Audit Log)**
   - تسجيل تاريخي لكل عملية إضافة، تعديل، حذف، أو دفع لضمان الشفافية والموثوقية.

---

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Framework**: Next.js 16 (App Router & Turbopack)
- **Frontend**: React 19, TypeScript
- **Styling**: CSS Tokens & Responsive Design System (Mobile Bottom Nav + Desktop Sidebar)
- **Icons**: Lucide React
- **PDF Generation**: HTML2PDF.js (Client-side vector rendering)
- **State & Storage**: React Context + LocalStorage Persistence

## 🚀 التشغيل محلياً (Getting Started)

1. **تثبيت الحزم**:
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير**:
   ```bash
   npm run dev
   ```
   افتح المتصفح على [http://localhost:3000](http://localhost:3000)

3. **تشغيل الاختبارات**:
   ```bash
   npm test
   ```

4. **البناء للإنتاج**:
   ```bash
   npm run build
   ```
